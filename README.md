# Processamento de Linguagem Natural

Repositório voltado ao estudo de técnicas de Processamento de Linguagem Natural.

---

## 🎯 Objetivos
- Compreender os conceitos básicos de Processamento de Linguagem Natural  
- Realizar uso de bibliotecas como re (expressões regulares), nltk, spacy e modelos recentes de LLM, como BERT 

---

## 🛠️ Ferramentas usadas
- Python: NumPy, Matplotlib, NLTK, SpaCy, Scikit-learn
- Google Colab

---

## 📂 Estrutura do repositório
- `data/` → Base de dados (corpus)
- `praticaX-pln/` → Práticas em processamento de lingaugem natural, onde X é a prática
- `pln-llm-classX` → Notebooks jupyter com práticas, onde X é a pratica
